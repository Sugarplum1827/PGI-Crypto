KEY FINDING

MGV recall is not the same as reliable MGV detection.

The best model recovers some MGV windows, but its precision is near zero because MGV is extremely rare. That result is reported as a limitation, not hidden behind overall accuracy.

IMPLEMENTATION BOUNDARY

The standard key-generation path remains separate.

PGI’s research model does not replace an approved random bit generator, prime-generation method, primality validation, or cryptographic review. No new-model PGI RSA keys were generated in the reported work.
